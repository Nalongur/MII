# MII 墨水屏终端原理图参考（SVG）

这些 SVG 是供在立创 EDA 中人工重画的连接参考，不是可直接投板的网表。

文件：

- `01_电源_USB_充电.svg`：USB-C、ESD、BQ24074、双线电池、软开关、3.3 V 电源和指示灯。
- `02_ESP32_按键_调试.svg`：ESP32-S3-MINI-1-N8、按键、USB、状态信号及测试点。
- `03_EPD0426A02_接口与升压.svg`：24 Pin FPC、SPI、SSD1677 外围升压及高压电容。
- `04_GNSS_BME280.svg`：E108-GN07IS、TPS22919、无源天线和 BME280 模块。

使用说明：

1. 先按网络名连接，不要按图中的视觉距离判断是否相连。
2. 所有器件引脚号在落图时仍需用所购具体型号的数据手册复核。
3. 红色为电源，蓝色为数字信号，绿色为控制/状态，黑色为地。
4. `DNP` 表示默认不装；`TP` 表示测试点。
5. EPD 高压部分以项目内 OSPTEK `T0426A02-A0` 转接板原理图为基准。
