# MII 墨水屏 GNSS 终端详细接线逻辑 v0.3

本文件用于在立创 EDA 中建立原理图网络。最终落图时，以器件原厂数据手册和已选商城封装的物理 Pad 编号为准；逐引脚 Excel 表用于逐项勾线和复核。

当前封装冻结：R1–R32 全部使用 0603；SW1–SW3 全部使用 ALPS Alpine `SKTDLDE010 / C115365`。

## 1. 电源域与开关机主链路

整机电源路径为：

`USB_5V → U3 BQ24074 → SYS_OUT → U5 TPS63021 → 3V3_MAIN`

电池路径为：

`BT1 BAT → U3 BAT；U3 PowerPath 自动在 USB 与电池之间管理 SYS_OUT`

关机时 U3 仍与电池、USB 相连，所以仍可充电；U4 STM6601 由 `SYS_OUT` 常供电。U4 的低有效 `/EN` 经 Q2 反相后控制 U5 的高有效 `EN`，从而切断或开启整机 `3V3_MAIN`。

## 2. J1 TYPE-C-31-M-12 / C165948

| J1 触点 | 网络 | 连接 |
|---|---|---|
| A1、A12、B1、B12 | GND | 全部并接地平面，座子附近加回地过孔 |
| A4、A9、B4、B9 | USB_5V | 全部并接；接 U3 Pin13 IN、D4 Pin1/K、C14 |
| A5 | USB_CC1 | R3 5.1 kΩ 到 GND，同时接 U2 Pin4 |
| B5 | USB_CC2 | R4 5.1 kΩ 到 GND，同时接 U2 Pin5 |
| A6、B6 | USB_DP_CONN | 两脚就近并接，接 U2 Pin1，再经 R5 22 Ω 到 ESP GPIO20 |
| A7、B7 | USB_DM_CONN | 两脚就近并接，接 U2 Pin2，再经 R6 22 Ω 到 ESP GPIO19 |
| A8、B8 | NC | SBU1、SBU2 不使用，不拉长支线 |
| 所有金属外壳/固定焊脚 | GND | 直接接大地铜并加多个过孔 |
| 塑胶定位柱 | 无网络 | 使用规格图规定的 NPTH 定位孔 |

注意：`TYPE-C-31-M-12` 的焊盘、槽孔、定位孔和 `PCB Edge` 位置必须严格照 C165948 专用封装/规格图，不得沿用旧 USB 座封装。A/B 面的 D+、D− 分别并接，才能保证正反插均可通信。CC1 和 CC2 必须各自独立使用一颗 5.1 kΩ 下拉，不得合并后共用一颗。

U2 TPD4E05U06 的 Pin1、Pin2、Pin4、Pin5 分别保护 D+、D−、CC1、CC2；Pin3 和 Pin8 接 GND，Pin6、Pin7、Pin9、Pin10 悬空。U2 是对地 ESD 阵列，不是串在信号线中的器件。D4 PESD5V0S1UL 为 VBUS TVS：Pin1/K 接 `USB_5V`，Pin2/A 接 GND。

## 3. U3 BQ24074 充电与 PowerPath

| U3 引脚 | 连接逻辑 |
|---|---|
| 1 TS | `BQ_TS`，R9 10 kΩ 到 GND；首版双线电池使用固定电阻，NTC1 不装 |
| 2、3 BAT | 并接 `BAT`，接 BT1 红线；C15 10 µF 到 GND |
| 4 CE | 直接接 GND，充电始终允许 |
| 5 EN2 | 接 GND |
| 6 EN1 | 接 `SYS_OUT`，与 EN2 组合为 USB500 模式 |
| 7 PGOOD | `PGOOD`，R12 10 kΩ 上拉到 3V3_MAIN，同时接 ESP GPIO47；低表示输入电源有效 |
| 8 VSS、EP | GND；EP 以地铜和热过孔散热 |
| 9 CHG | `CHG_N`，接 LED1 阴极和 D5 阴极；低表示充电，完成时高阻，故障时闪烁 |
| 10、11 OUT | 并接 `SYS_OUT`；C16 10 µF 到 GND；供 U4 和 U5 |
| 12 ILIM | R8 1.5 kΩ 到 GND，不悬空；当前 EN2=0、EN1=1 的 USB500 模式使用芯片固定约 500 mA 输入上限，R8 仅在以后切换为 EN2=1、EN1=0 的可编程模式时生效（约 1.0 A） |
| 13 IN | `USB_5V`；C14 1 µF 到 GND |
| 14 TMR | 悬空，使用默认安全计时 |
| 15 ITERM | 悬空，使用默认终止比例 |
| 16 ISET | R7 2.21 kΩ 到 GND，目标充电电流约 400 mA |

BT1 为带保护板的 1S 1200 mAh 聚合物电池：红线接 `BAT`，黑线接 GND，必须在回流完成后手焊并做导线应力释放。400 mA 约为 0.33C，投板前仍需用电池供应商给出的最大充电电流复核。

充电指示灯：`SYS_OUT → R10 3.3 kΩ → LED1 红灯阳极；LED1 阴极 → CHG_N`。因此 U3 拉低 CHG 时红灯点亮。读取充电状态时，ESP GPIO13 接 `CHG_SENSE`，由 R11 100 kΩ 上拉到 3V3_MAIN；D5 阳极接 `CHG_SENSE`，阴极接 `CHG_N`，用于隔离关机电源域。

## 4. U4 STM6601 与按键

| U4 引脚 | 连接逻辑 |
|---|---|
| 1 VCC | `SYS_OUT`，C17 0.1 µF 到 GND |
| 2 SR | `PWR_SR`，接 D7 阳极；D7 阴极接 SW3 的 `KEY2_NODE` |
| 3 VREF | 只接 C18 1 µF 到 GND，不带其他负载 |
| 4 PSHOLD | 接 ESP GPIO21，R32 100 kΩ 下拉到 GND |
| 5 CSRD | C19 0.47 µF 到 GND，约 4.7 s 长按硬复位判定 |
| 6 PB | `PWR_PB`，SW1 按下接 GND |
| 7 VCC_LO | 悬空 |
| 8 PBOUT | `PWR_PBOUT`，R16 10 kΩ 上拉 3V3_MAIN，接 ESP GPIO2 |
| 9 /EN | `STM_EN_N`，经 R13 100 kΩ 到 Q2 基极 |
| 10 /RST | `ESP_EN`，接 ESP Pin45 EN，R18 10 kΩ 上拉 3V3_MAIN |
| 11 /INT | `PWR_INT`，R17 10 kΩ 上拉 3V3_MAIN，接 ESP GPIO14 |
| 12 GND | GND |

Q2 MMBT3904 反相：发射极接 GND，基极由 R13 接 `STM_EN_N`，R15 1 MΩ 将基极下拉；集电极接 `TPS_EN`，R14 100 kΩ 将 `TPS_EN` 上拉到 `SYS_OUT`。U4 `/EN` 低时 Q2 截止，R14 将 U5 EN 拉高，系统开机；U4 `/EN` 高时 Q2 导通，U5 EN 被拉低，系统关机。

按键定义：

- SW1 `SKTDLDE010` 电源键：一端 `PWR_PB`，另一端 GND。
- SW2 `SKTDLDE010` 功能键 1：一端 `FUNC1_BOOT`/ESP GPIO0，另一端 GND；正常运行作功能键，上电或复位时兼作 BOOT。
- SW3 `SKTDLDE010` 功能键 2：一端 `KEY2_NODE`，另一端 GND。`KEY2_NODE` 分别接 D6、D7 阴极；D6 阳极接 `FUNC2_GPIO`/ESP GPIO1，并由 R31 10 kΩ 上拉；D7 阳极接 U4 SR。这样单按可由 GPIO1 读取，同时可参与 STM6601 的 PB+SR 长按硬复位逻辑。

建议固件在启动后尽快将 GPIO21 拉高以保持开机；正常关机时先保存状态、关闭 GNSS、让墨水屏刷新完成，再释放 GPIO21。

## 5. U5 TPS63021 固定 3.3 V

| U5 引脚 | 连接逻辑 |
|---|---|
| 1 VINA | `SYS_OUT`，C22 0.1 µF 到 GND |
| 2 GND、EP/PGND | GND，按 TI 推荐回流布局连接 |
| 3 FB | 直接接 `3V3_MAIN`/VOUT，不悬空 |
| 4、5 VOUT | 并接 `3V3_MAIN`，C23、C24、C25 各 22 µF 到 GND |
| 6、7 L2 | 并接 `TPS_L2`，接 PCB 电感 L2 的一端 |
| 8、9 L1 | 并接 `TPS_L1`，接 PCB 电感 L2 的另一端 |
| 10、11 VIN | 并接 `SYS_OUT`，C20、C21 各 10 µF 到 GND |
| 12 EN | `TPS_EN`，接 Q2 集电极和 R14 |
| 13 PS/SYNC | 接 GND，使用省电模式 |
| 14 PG | 首版悬空，可留小测试点 |

功率电感 L2 为 1.5 µH。U5、L2、输入/输出电容必须形成最小功率回路，L1/L2 开关节点铜皮要短小，不得靠近 GNSS 射频线和天线。

绿色开机灯：`3V3_MAIN → R20 4.7 kΩ → LED2 阳极；LED2 阴极 → ESP GPIO48`，R19 100 kΩ 将 GPIO48/LED 阴极默认上拉。GPIO48 输出低时点亮，输出高或高阻时熄灭。

## 6. ESP32-S3-MINI-1-N8 主要信号分配

| GPIO | 用途 |
|---|---|
| GPIO0 | SW2 功能键1 / BOOT |
| GPIO1 | SW3 功能键2，经 D6 隔离 |
| GPIO2 | STM6601 PBOUT，低有效 |
| GPIO4 | BAT_ADC，R28 1 MΩ / R29 330 kΩ 分压，C29 0.1 µF 滤波 |
| GPIO5 / GPIO6 | BME280 SDA / SCL |
| GPIO7 / 8 / 9 / 10 | EPD BUSY / RST / DC / CS |
| GPIO11 / GPIO12 | EPD MOSI / SCLK |
| GPIO13 | CHG_SENSE，低表示充电 |
| GPIO14 | STM6601 /INT |
| GPIO15 | GNSS_EN，高开低关 |
| GPIO16 | GNSS 1PPS |
| GPIO17 | ESP TX → GNSS RXD Pin21 |
| GPIO18 | ESP RX ← GNSS TXD Pin20 |
| GPIO19 / GPIO20 | USB D− / D+ |
| GPIO21 | PSHOLD |
| GPIO47 | BQ24074 PGOOD，低有效 |
| GPIO48 | 绿色开机灯，低有效 |
| GPIO43 / GPIO44 | 调试 UART TX / RX 测试点 |

ESP 模块 Pin3 接 3V3_MAIN；全部 GND 焊盘及中央地焊盘接完整地平面。Pin45 EN 接 `ESP_EN`，使用 R18 10 kΩ 上拉，并受 U4 `/RST` 控制。ESP PCB 天线端必须伸到 PCB 边缘，天线正下方及前方所有铜层禁铜、禁走线、禁器件，并远离 GNSS 天线。

## 7. GNSS 电源、串口与天线

U6 TPS22919DCKR 为 6 脚 SC70：Pin1 IN 接 3V3_MAIN并放 C30 1 µF；Pin2 GND；Pin3 ON 接 GPIO15，并由 R27 100 kΩ 下拉；Pin4 NC；Pin5 QOD 与 Pin6 VOUT 一起接 `3V3_GNSS`；Pin6 VOUT 旁放 C31 1 µF。GNSS 模块入口再放 C32 10 µF 和 C33 0.1 µF。

E108-GN07IS：Pin23 VCC 接 3V3_GNSS；Pin10、12、13、24 接 GND；Pin20 TXD 接 ESP GPIO18；Pin21 RXD 接 ESP GPIO17；Pin3 1PPS 接 GPIO16；Pin11 RF_IN 经 C34 56 pF 串联到 J3 中心信号；Pin22 VBCKP 悬空，不保留星历；Pin8 RESET_N 悬空；Pin9 VCC_RF 悬空，因为使用无源天线；其余 NC 脚均悬空。

天线链路为：`U7 Pin11 RF_IN → C34 56 pF → J3 U.FL SIG → 50 Ω同轴线 → 18×18×2 mm无源陶瓷天线`。J3 两侧地脚接连续地平面，并就近密集打地过孔。射频走线保持 50 Ω、短、直、无测试点、无分叉；其两侧留地并远离 U5/L2、EPD 高压泵、USB D+/D− 和 ESP 天线。陶瓷白色辐射面朝塑料背板，天线前方不放电池、金属背板、屏蔽罩或大面积铜。最终仍需整机装配后实测信噪比和定位时间。

| 4 | NC | 悬空 |
| 5 | VSH2 | C2 4.7 µF/25 V 到 GND |
| 6、7 | GND | GND |

| 9 | BUSY_N | ESP GPIO7 |
| 10 | RST_N | ESP GPIO8 |
| 11 | DC | ESP GPIO9 |
| 12 | CSB | ESP GPIO10 |
| 13 | SCL | ESP GPIO12 |
| 14 | SDA | ESP GPIO11 |
| 15 | VDDIO | 3V3_MAIN |
| 16 | VCC | 3V3_MAIN，C6 22 µF + C7 0.1 µF 到 GND |
| 17 | VSS | GND |
| 18 | VDD | 只接 C8 1 µF/25 V 到 GND，不接 3.3 V |
| 19 | VPP | 悬空 |

| 21 | VGH | D3 K、C5 4.7 µF、C10 1 µF 到 GND |
| 22 | VSL | C11 4.7 µF/25 V 到 GND |
| 23 | VGL | D1 K、C1 4.7 µF、C12 1 µF 到 GND |
| 24 | VCOM | C13 1 µF/25 V 到 GND |

EPD 升压外围按官方转接板连接：L1 10 µH 从 3V3_MAIN 接到 `EPD_SW`；Q1 D 接 EPD_SW、G 接 GDR、S 接 RESE；D3 A 接 EPD_SW、K 接 VGH；C3 跨接 EPD_SW 与 `EPD_PUMP`；D1 A 接 EPD_PUMP、K 接 VGL；D2 A 接 GND、K 接 EPD_PUMP。所有高压电容紧靠 FPC，EPD_SW、VGH、VGL、VSH1、VSH2、VSL、VCOM 不得穿过 MCU、GNSS 和 USB 区域。

屏幕 FPC 金手指位于显示正面，但这只确定接触面，不自动确定 Pin1 左右方向。画 PCB 前必须用屏幕正视机械图、FPC 上的 Pin1 标记和连接器原厂图三者交叉核对。

## 9. U8 ZY-BME280 模块

根据模块应用原理图与实物丝印冻结焊盘编号：左侧自上而下 Pin1=VCC、Pin2=GND、Pin3=SCL、Pin4=SDA；右侧自下而上 Pin5=NC、Pin6=SDO、Pin7=GND、Pin8=3.3V。板体平面尺寸约 14.86 × 11.50 mm；图中的 2.54 mm 是相邻焊盘中心距，不是模块高度。首版估算封装采用两侧各 4 个 2.2 × 1.6 mm SMT 焊盘，纵向节距 2.54 mm，焊盘中心 X=±6.95 mm、Y=±3.81/±1.27 mm；到货后再按实物修订。

默认装配：R23 0 Ω 给 Pin8（3.3V）供 `3V3_MAIN`，R24 不装；R25 0 Ω 将 Pin6（SDO）接 GND，地址为 0x76，R26 不装；Pin3 SCL 接 GPIO6，Pin4 SDA 接 GPIO5，R21/R22 各 4.7 kΩ 上拉到 `3V3_MAIN`。R23/R24 不得同时装，R25/R26 不得同时装。模块高度适合约 4.3 mm 腔体，但 PCB 前仍应按实物复测焊盘间距和外形公差。

## 10. 布板硬约束

- 0.6 mm 四层板、单面贴片：L1 元件/信号，L2 连续整地，L3 电源与必要信号，L4 地/低速信号。
- USB-C、FPC、侧按键处增加结构支撑；J1 专用槽孔和板边尺寸不可凭图片估算。
- USB D+/D− 按 90 Ω差分控制，等长且少过孔；R5/R6 靠近 ESP，U2 靠近 J1。
- BQ24074 EP、TPS63021 EP/PGND、ESP 中央地焊盘必须可靠接地并布置热/回流过孔。
- GNSS 射频区与开关电源、EPD 高压区物理隔离；天线同轴线不要贴着电感或电池大面积走线。
- 所有单面 SMT 器件高度须小于约 4.3 mm 腔体，并为焊锡、胶带和外壳公差留余量。

## 11. 仍需在投板前确认

1. J2 实际 FPC Pin1 左右方向及连接器翻盖方向。
2. U8 BME280 模块的实际厚度、焊盘宽度和板边余量；14.86 × 11.50 mm板体、2.54 mm焊盘节距、引脚编号与供电路径已按用户资料冻结，首版允许使用估算焊盘。
3. 所有二极管、MOSFET、NPN 的所购品牌 Pad 编号与 A/K、G/S/D、B/E/C 对应关系。
4. TYPE-C-31-M-12 专用封装与实物样件的板边、槽孔、定位柱及壳体高度。
5. 电池供应商允许的充电电流和电池导线/保护板的瞬时放电能力。
