## 2. 电源树（第一版）

```text
USB-C 5 V
   │
   ├─ CC1、CC2：各 5.1 kΩ 下拉到 GND
   ├─ USB D-：ESP32 GPIO19
   ├─ USB D+：ESP32 GPIO20
   │
   └─ BQ24074 单节锂电充电/PowerPath
          ├─ BAT：1200 mAh 聚合物电池（电池本体必须带保护板）
          └─ SYS/OUT：约 3.5～4.4 V
                 │
                 └─ TPS63021 固定 3.3 V 升降压
                        ├─ 3V3_MAIN：ESP32、BME280、墨水屏 VCC/VDDIO
                        ├─ 磁珠隔离后 3V3_GNSS：E108-GN07IS
                        └─ 墨水屏外置高压驱动电路输入
```

暂定充电电流 500 mA。落图前必须用所购电池规格书确认允许充电电流、NTC 配置和保护板参数。0.6 mm PCB 上 BQ24074 的散热焊盘和铺铜必须按参考设计处理。

TPS63021 为固定 3.3 V、4 A 开关限流的升降压器件，电感与输入/输出电容紧贴芯片。电源开关节点、墨水屏升压电路、ESP32 天线与 GNSS 区域必须物理分开。

## 3. ESP32-S3 GPIO 初步分配

以下分配避开 GPIO0、GPIO3、GPIO45、GPIO46 等启动配置脚作为普通外设控制。

| 功能 | ESP32-S3 GPIO | 对端 |
|---|---:|---|
| USB D- | GPIO19 | USB-C D- |
| USB D+ | GPIO20 | USB-C D+ |
| EPD SPI SCLK | GPIO12 | 屏幕 Pin 13 SCL |
| EPD SPI MOSI | GPIO11 | 屏幕 Pin 14 SDA |
| EPD CS | GPIO10 | 屏幕 Pin 12 CSB |
| EPD D/C | GPIO9 | 屏幕 Pin 11 DC |
| EPD RESET | GPIO8 | 屏幕 Pin 10 RST_N |
| EPD BUSY | GPIO7 | 屏幕 Pin 9 BUSY_N |
| GNSS UART RX | GPIO18 | E108 Pin 20 TXD |
| GNSS UART TX | GPIO17 | E108 Pin 21 RXD |
| GNSS 1PPS | GPIO16 | E108 Pin 3 1PPS |
| GNSS RESET | GPIO15 | E108 Pin 8 RESET_N（可不接，悬空） |
| BME280 I2C SDA | GPIO5 | BME280 SDA |
| BME280 I2C SCL | GPIO6 | BME280 SCL |
| 电池电压检测 | GPIO4/ADC | BAT 分压及滤波 |
| BOOT 按键 | GPIO0 | 按下接地，保留上拉 |
| EN/复位按键 | EN | 按下接地，按乐鑫参考电路配置 RC |

GPIO 分配在增加按键、蜂鸣器、状态灯等需求后仍可调整。

## 4. E108-GN07IS 连接

| 模块引脚 | 连接方式 |
|---|---|
| Pin 23 VCC | 3V3_GNSS；模块近端 10 µF + 100 nF 去耦 |
| Pin 10/12/13/24 GND | 完整地连接，多过孔回地 |
| Pin 20 TXD | ESP32 GPIO18（UART RX） |
| Pin 21 RXD | ESP32 GPIO17（UART TX） |
| Pin 3 1PPS | ESP32 GPIO16，可串 33～100 Ω 阻尼电阻 |
| Pin 8 RESET_N | 默认悬空；需要软件控制时接 GPIO15，避免外部强上拉 |
| Pin 22 VBCKP | 第一版预留 0 Ω 选择：可接 3V3_GNSS，也可悬空；后续根据待机目标决定 |
| Pin 11 RF_IN | 经过 56 pF 串联电容连接 IPEX1/U.FL 中心端 |
| Pin 9 VCC_RF | 无源天线方案悬空；预留 82 nH DNP 位用于将来改有源天线 |
| 其余 NC | 悬空，不互连 |

RF_IN 到 IPEX 的走线按 50 Ω 控制，越短越好；56 pF 靠近模块 RF_IN。天线区域不要布置电池、屏蔽罩、电感、高速线或金属背板。

## 5. EPD0426A02 24 Pin 接口

屏幕采用 4 线 SPI：Pin 8 BS 通过 0 Ω 下拉到 GND。

| Pin | 信号 | 第一版处理 |
|---:|---|---|
| 1 | NC | 悬空 |
| 2 | GDR | 接外置墨水屏升压 MOS 管栅极 |
| 3 | RESE | 接 2.2 Ω/1% 电流检测电阻网络 |
| 4 | NC | 悬空 |
| 5 | VSH2 | 按原厂参考电路接高压电容 |
| 6、7 | GND | 接地 |
| 8 | BS | 0 Ω 下拉，选择 4 线 SPI |
| 9 | BUSY_N | ESP32 GPIO7 |
| 10 | RST_N | ESP32 GPIO8 |
| 11 | DC | ESP32 GPIO9 |
| 12 | CSB | ESP32 GPIO10 |
| 13 | SCL | ESP32 GPIO12 |
| 14 | SDA | ESP32 GPIO11 |
| 15 | VDDIO | 3.3 V，近端 1 µF |
| 16 | VCC | 3.3 V，近端去耦 |
| 17 | VSS | 接地 |
| 18 | VDD | 按原厂参考电路接 1 µF |
| 19 | VPP | 悬空 |
| 20 | VSH1 | 按原厂参考电路 |
| 21 | VGH | 4.7 µF/25 V |
| 22 | VSL | 4.7 µF/25 V |
| 23 | VGL | 4.7 µF/25 V |
| 24 | VCOM | 1 µF/25 V |

外置高压驱动器件按原厂清单：

- L1：47 µH，参考 NRH3010T470MN；
- Q1：Si1304BDL 或 NX3008NBK；
- D1～D3：MBR0530；
- R2：2.2 Ω，0603，1%；
- C1～C3：1 µF，0603，X5R，25 V；
- C4～C9：4.7 µF，0805，X5R，25 V；
- C10：1 µF，0805，X7R，25 V。

24 Pin 0.5 mm FPC 座的上接/下接形式暂不锁定，必须先拍清楚实际屏幕 FPC 金手指朝向和背面完整型号。

## 6. BME280 连接原则

若继续使用 ZY-BME280 小模块：

- 供电接 3.3 V，不使用 5 V；
- I2C SDA/SCL 各预留 4.7 kΩ 上拉到 3.3 V；
- 最终网络必须按实物丝印确认，不能仅按商品主图猜测；
- 传感器开孔应与外界空气连通，远离充电芯片、电感、ESP32 和电池，避免自热造成温度偏高。

## 7. 布局硬约束

1. ESP32-S3-MINI-1 板载天线伸到 PCB 边缘，天线下方和前方按乐鑫要求禁止铺铜、走线和放置金属结构。
2. 18×18×2 mm GNSS 陶瓷天线白色面朝塑料背板；预留至少 20×20×2.5 mm 机械空间。
3. GNSS 模块与天线远离 TPS63021 电感、EPD 47 µH 电感、USB 和 ESP32 天线。
4. EPD 高压回路面积必须小，高压电容和二极管靠近 FPC 座。
5. 电池不得参与回流焊；主板完成后再连接或点焊带保护板电池。
6. 所有器件和焊点的实装高度需控制在 4.3 mm 内，并预留背板公差与绝缘膜厚度。

## 8. 下一步必须确认

1. 原理图/PCB 使用的软件：KiCad、立创 EDA 或 Altium Designer。
2. ESP32-S3-MINI-1 的完整后缀：N8、N4R2 等。
3. 实物屏幕 FPC 正反面高清照片，确定连接器接触方向。
4. ZY-BME280 模块两面高清照片或商品链接，确定 8 个焊盘定义。
5. 充电口是否固定为 USB-C，以及是否需要边充边用。
6. 是否需要实体电源开关、状态灯、功能按键和蜂鸣器。
7. 电池保护板是否已经集成，以及电池插接方式或焊线方式。
